ScheduleSync 개인정보처리방침

시행일: 2026년 11월 22일

1. 개요

ScheduleSync(이하 "앱")는 개인이 자기 PC에서 실행하는 일정 동기화 도구입니다. 앱 개발자 본인만 사용하며, 일반 사용자에게 제공하는 서비스가 아닙니다.

2. 접근하는 Google 사용자 데이터

앱은 사용자가 로그인해 허용한 경우에만 Google Calendar API로 다음 데이터에 접근합니다.

  • 사용자가 소유한 캘린더 목록 (동기화 대상 캘린더를 고르기 위해)
  • 사용자가 고른 대상 캘린더의 일정과 일정 라벨 (일정을 추가·수정·삭제하고 색을 지정하기 위해)

3. 데이터의 사용

위 데이터는 네이버 캘린더의 일정을 사용자의 Google 캘린더로 복사하고, 그 이력을 관리하는 데에만 사용합니다. 광고, 분석, 프로필 작성 등 다른 목적으로는 사용하지 않습니다.

4. 저장과 공유

  • 로그인 정보(토큰)와 동기화 기록은 사용자 본인의 PC에만 저장합니다.
  • 데이터를 개발자의 서버나 제3자에게 보내거나 공유·판매하지 않습니다.

5. Google API 정책 준수

앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책의 제한된 사용(Limited Use) 요구사항을 포함해 이 정책을 따릅니다.

6. 데이터 삭제와 권한 해제

PC에 저장된 로그인 정보와 기록 파일을 지우면 앱이 가진 데이터는 모두 삭제됩니다. Google 계정의 타사 앱 권한 페이지에서 앱의 접근 권한을 언제든지 해제할 수 있습니다.
